# Web Application Vulnerability Assessment

## Objective
This repository contains a professional Vulnerability Assessment Report (VAPT) conducted as part of a cybersecurity internship. The goal of this task was to perform a passive, read-only security analysis of a public-facing web application to identify common security misconfigurations, classify their risk, and provide business-friendly remediation steps.

## Target Scope
*   **Target:** `http://scanme.nmap.org` (A permitted, intentionally hosted target by the Nmap Security Project).
*   **Methodology:** Passive reconnaissance, service enumeration, and non-intrusive vulnerability scanning. 

## Tools Utilized
*   **Nmap:** For port scanning and service version enumeration.
*   **OWASP ZAP:** Utilized strictly in Passive Mode to identify missing HTTP security headers and client-side vulnerabilities.
*   **Browser Developer Tools:** For manual inspection of headers and cookies.
*   **Canva:** For designing the final executive report.

## Deliverables
1.  **Vulnerability_Assessment_Report.pdf** - The final executive and technical report detailing the 5 discovered vulnerabilities, business risks, and remediation strategies.
2.  **Evidence Screenshots** - Images of terminal outputs and tool findings demonstrating the issues.

## Disclaimer
This assessment was conducted strictly following ethical guidelines. No active exploitation, brute-forcing, or denial-of-service attacks were performed.
